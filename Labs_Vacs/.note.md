## 3. Script `2.11.LABSP_Create.ps1` — Création de la VM Client

Emplacement : `C:\Users\Baine\SynologyDrive\GitHub\Labs\Labs_Vacs\2.11.LABSP_Create.ps1`

### Bugs rencontrés au premier boot (et corrigés)

| # | Symptôme | Correction apportée |
|---|---|---|
| 1 | Arborescence de dossiers incorrecte | Fix lignes 20 à 23 |
| 2 | Le client n'a pas fonctionné | Le CSV ne contenait pas l'information OS — corrigé |
| 3 | Le nombre de processeurs ne s'est pas mis à jour | Ligne pour le processeur manquante — ajoutée |
| 4 | La VM client démarre sur le HDD au lieu du DVD | Fix lignes 47 à 49 |
| 5 | La machine ne s'affiche pas automatiquement | *(non résolu à ce stade — à revoir)* |

### Logique du script (création de la VM)

```powershell
Set-Location "..\$DirName\Client"

# Creation du disque dur virtuel
New-VHD -Path ".\SRV_Client-DISK1.vhdx" -SizeBytes $sizemain -Dynamic

# Creation de la VM
New-VM -Name $VMname `
       -Generation $gen `
       -MemoryStartupBytes $ram `
       -VHDPath ".\SRV_Client-DISK1.vhdx" `
       -Path "." `
       -SwitchName $switch

# Configuration des ressources de la VM
Set-VMMemory -VMName $VMname -DynamicMemoryEnabled $false
Set-VMProcessor -VMName $VMname -Count $cpu

# Activation du Secure Boot (recommande pour Windows 11)
Set-VMFirmware -VMName $VMname -EnableSecureBoot On

# Configuration du TPM virtuel
Set-VMKeyProtector -VMName $VMname -NewLocalKeyProtector
Enable-VMTPM -VMName $VMname

# Attache de l'ISO Windows 11
Add-VMDvdDrive -VMName $VMname -Path "D:\PARENT\Win11_25H2_English_x64_v2.iso"

# Definit le lecteur DVD comme premier peripherique de demarrage
$dvd = Get-VMDvdDrive -VMName $VMname
Set-VMFirmware -VMName $VMname -FirstBootDevice $dvd

# Demarrage de la VM
Start-VM -Name $VMname
Start-Sleep -Seconds 5

# Ouverture de la console de la VM
Start-Process "vmconnect.exe" -ArgumentList "localhost", $VMname

# Affichage des VM en cours d'execution
Get-VM | Where-Object { $_.State -eq "Running" }
```

> Note : le bloc de création (`New-VHD`/`New-VM`) apparaissait deux fois dans les notes brutes — probable copier-coller en double, dédupliqué ici.

## 4. Script `2.21.LABSP_Config.ps1` — Configuration serveur (promotion DC, réseau, DNS)

### Erreurs rencontrées lors de l'exécution

| # | Erreur | Détail |
|---|---|---|
| 1 | `The credential is invalid` | `PSSessionStateBroken` — identifiants invalides pour la session distante vers `SRV-AD` |
| 2 | `Element not found` sur `New-NetIPAddress` | `Windows System Error 1168` — l'interface réseau ciblée n'a pas été trouvée par le CIM |
| 3 | `No MSFT_DNSClientServerAddress objects found with property 'InterfaceAlias' equal to 'Ethernet'` | Le nom d'interface `Ethernet` ne correspondait pas au nom réel de l'interface sur la machine |
| 4 | `No matching MSFT_NetAdapterBindingSettingData objects found` (désactivation IPv6) | Même cause : interface `Ethernet` introuvable via la requête CIM |
| 5 | `Attempted to divide by zero` à la ligne 58 (`$percent = ($i / $duration) * 100`) | `$duration` valait `0` au moment du calcul — division par zéro |

### Résultat final (une fois les blocages résolus)

- **Installation réussie** des rôles : Active Directory Domain Services, Group Policy Management, Remote Server Administration Tools, Active Directory Administrative Center.
- **Installation réussie** des rôles : DNS Server, DNS Server Tools.
- Avertissements informatifs (non bloquants) :
  - Adaptateur réseau physique sans IP statique assignée pour IPv4/IPv6.
  - Délégation DNS non créée automatiquement pour la zone parente de `home.lan` (normal si aucune infrastructure DNS existante à déléguer).
- Promotion du contrôleur de domaine : `DCPromo.General.3` → `Operation completed successfully`, `RebootRequired: False`.
